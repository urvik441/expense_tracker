# 💰 Expense Tracker App

A modern and user-friendly **Expense Tracker** mobile application built with **React Native** and **Expo**. This app helps users record, organize, and analyze their daily expenses with an intuitive calendar-based interface.

Users can select a **year**, **month**, and **date** to manage expenses for a specific day. Multiple expenses can be added for the same date, categorized with predefined categories and icons, making expense tracking simple and organized.

## ✨ Features

* 📅 Year → Month → Date navigation
* ➕ Add multiple expenses for a single day
* 📝 Edit and delete existing expenses
* 💾 Offline data storage using AsyncStorage
* 🏷️ Predefined expense categories with icons
* 📂 Categories with subcategories (Food, Grocery, Shopping, Petrol, Milk, Rent, etc.)
* 🔍 Search and filter expenses
* 📊 Daily, monthly, and yearly expense summaries
* 💰 Automatic expense calculations
* 📈 Dashboard with expense statistics
* 🌙 Light and Dark theme support
* 📱 Responsive and clean mobile UI
* ⚡ Fast and smooth performance
